# รูปจริง: ตั้งชื่อตามรหัสอาคาร

วางรูปทั้งหมดในโฟลเดอร์นี้ได้เลย ใช้ **รูปเดียวต่ออาคาร** ตั้งชื่อเป็นรหัสตึก

ตัวอย่าง:

- `EN14.jpg` — อาคารวิศวกรรมเคมี
- `EN09.jpg` — CB
- `EN17.jpg` — Workshop
- `EN16.jpg` — ตึกเพียรวิจิตร

รหัสที่รองรับ: EN01, EN02, EN04, EN05, EN06, EN07, EN08, EN09, EN10, EN11, EN12, EN13, EN14, EN15, EN16, EN17, EN18
ไม่มี EN03 เพราะรื้อแล้ว ใช้ EN ตัวใหญ่และเลขสองหลักตามตัวอย่าง
ไม่ต้องสร้างโฟลเดอร์แยกตึก และไม่ต้องตั้งชื่อ front, entry หรือ rear

## รูปแบบไฟล์

รองรับ `.jpg`, `.png`, `.webp` เช่น `EN14.png` ใช้อย่างใดอย่างหนึ่งเพียงไฟล์เดียวต่อรหัส
แอปลอง JPG → PNG → WebP ถ้ามีชื่อซ้ำหลายชนิดจะแสดง JPG ก่อน
แนะนำกว้าง 1400–2200 px ไฟล์ประมาณไม่เกิน 2 MB ไม่ต้องครอปเป็นสี่เหลี่ยม
วางหรือเปลี่ยนไฟล์แล้วกด **รีเฟรชรูป** ในแอปได้เลย ไม่ต้องแก้โค้ดหรือสั่ง build
ถ้ายังไม่มีรูป แอปจะแสดงชื่อไฟล์ที่ต้องวางแทนภาพ
