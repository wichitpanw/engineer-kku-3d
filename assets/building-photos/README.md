# รูปจริง: อาคารละหนึ่งรูป

วาง **รูปเดียวต่ออาคาร** ในโฟลเดอร์รหัสตึก ใช้ชื่อ `front.jpg` เหมือนกันทุกโฟลเดอร์

ตัวอย่าง:
- `EN14/front.jpg` — อาคารวิศวกรรมเคมี
- `EN09/front.jpg` — CB
- `EN17/front.jpg` — Workshop
- `EN16/front.jpg` — ตึกเพียรวิจิตร

โฟลเดอร์ทุกอาคารเตรียมไว้แล้ว (ไม่มี EN03 เพราะรื้อแล้ว)
เลือกรูปตัวแทนหนึ่งรูปที่เห็นอาคารชัด ไม่ต้องแยกภาพทางเข้า ด้านหลัง หรือแต่ละจุดสำรวจ
แท็บ ภาพจริง แสดงรูปเดียวของอาคารที่เลือก ไม่มีตัวเลือกมุมหรือปุ่มเลื่อนรูป

## รูปแบบไฟล์

รองรับ `front.jpg`, `front.png` หรือ `front.webp` เลือกวางอย่างใดอย่างหนึ่งเพียงไฟล์เดียว
แอปลอง JPG → PNG → WebP ถ้ามีชื่อซ้ำหลายชนิดจะแสดง JPG ก่อน
แนะนำกว้าง 1400–2200 px ไฟล์ประมาณไม่เกิน 2 MB ไม่ต้องครอปเป็นสี่เหลี่ยม
วางหรือเปลี่ยนไฟล์แล้วกด **รีเฟรชรูป** ในแอปได้เลย ไม่ต้องแก้โค้ดหรือสั่ง build
ถ้ายังไม่มีรูป แอปจะแสดงชื่อไฟล์ที่ต้องวางแทนภาพ
